# 这是谐音梗（游戏框架）

一个模仿 Steam 游戏《这是谐音梗》的网页小游戏框架，纯 HTML / CSS / JavaScript，
无需任何依赖、无需构建，双击 `index.html` 即可开玩。

## 目录结构

```
xieyingeng/
├── index.html          页面结构（首页 / 游戏页）
├── README.md
└── assets/
    ├── css/style.css   全部样式（移动端优先，自适应）
    ├── img/            谜题图：1.png、2.png、3.png ……
    └── js/
        ├── levels.js   ★ 关卡数据（只需改这个）
        └── game.js     游戏逻辑（渲染 / 揭晓 / 存档）
```

## 运行

- 直接双击 `index.html`（推荐用 Chrome / Edge / Safari）。
- 若要通过本地服务器运行：

  ```bash
  cd xieyingeng
  python -m http.server 8000
  # 浏览器打开 http://127.0.0.1:8000
  ```

## 玩法

1. 看 **谜题图片**。
2. 参考顶部常驻的 **类别提示** 自己想答案。
3. 点 **「提示」** 看一句话思路（不透露答案）。
4. 点 **「答案」** —— 答案以**竖排文字**显示在图片右侧，同时展示解析、解锁下一关。

> 答案不再使用图片，改为文字，显示在图片一侧。

## 谜题图片路径约定（按关卡编号自动查找）

**不需要在关卡里写路径**，程序按关卡 `id` 自动拼：

```
assets/img/<id>.<扩展名>
```

例如第 1 关 → `assets/img/1.png`。

- 扩展名会自动依次尝试：`png → jpg → jpeg → webp → gif → svg → avif`，
  命中即用；命中过的扩展名会被记住，后续关卡不再重复试错。
- 找不到图片时，图片区会提示"暂未找到图片"并列出尝试过的路径，方便排查。

## 关卡字段

编辑 `assets/js/levels.js`：

```js
{
  id: 2,                  // 关卡编号 → 图片 assets/img/2.*
  category: "婚礼",        // 类别提示（常驻显示）
  answer: "美满",          // 答案文字（显示在图片一侧，竖排）
  hint: "一句话思路……",    // 点「提示」时显示
  desc: "揭晓后的解析……",  // 揭晓答案后显示
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | ✅ | 关卡编号，决定解锁顺序，也是图片文件名 |
| `category` | ✅ | 类别提示，常驻显示在游戏页顶部 |
| `answer` | ✅ | 答案文字，揭晓后竖排显示在图片右侧 |
| `hint` | 建议 | 点「提示」时显示的一句话思路 |
| `desc` | 建议 | 揭晓答案后的解析文字 |
| `image` | 可选 | 手动指定谜题图路径，覆盖路径约定 |

## 添加新关卡

以第 2 关为例：

1. 把谜题图放成 `assets/img/2.png`（竖图或方图都行，程序自动适配比例）。
2. 在 `levels.js` 里加一条 `{ id: 2, category, answer, hint, desc }`。

## 其它

- **进度存档**：浏览器 `localStorage`，键名 `xieyingeng_progress_v1`，
  记录「已揭晓答案」的关卡；首页底部有「重置进度」按钮。
- **解锁规则**：第 1 关默认解锁，揭晓一关答案后解锁下一关。
- **图片适配**：图片框按图片真实比例自动调整；揭晓答案时会自动缩小，
  给右侧的答案文字让出空间。窗口缩放时实时重排。
- **适配**：移动端优先，最大宽度 560px 居中，窄屏自动缩小字号与间距。
